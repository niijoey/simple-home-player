# Simple Home player

A one-page YouTube player used by the Simple Home app on an LG TV.
YouTube only lets its player run on pages that have a web address, so the TV app
shows this page full screen and sends it play/pause/skip commands.

Use: `https://niijoey.github.io/simple-home-player/?v=<11-character video id>`

It holds no personal data and accepts commands only from the page that embeds it.
